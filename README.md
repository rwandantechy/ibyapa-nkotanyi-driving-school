# IBYAPA.COM

**Imyitozo y'Ikizamini cya Permi mu Rwanda**

Practice for Rwanda's Driving License Exam in Kinyarwanda, French, and English.

Live at [ibyapa.com](https://ibyapa.com)

---

## What is IBYAPA?

IBYAPA is a web app that helps people in Rwanda prepare for the provisional driving license (Permi) exam. It provides practice questions covering road signs, traffic rules, and driving regulations, the same topics tested by Rwanda National Police (RNP).

---

## Features

- Multilingual: Kinyarwanda, Français, and English
- Practice questions with instant feedback
- Correct answers to review your mistakes
- Works on mobile and desktop
- Sign in to track your progress

---

## Tech Stack



- **Frontend:** REACT
- **Backend / Auth:** EXPRESS, NODE,JS / Firebase, MONGODB


---

## Getting Started

```bash
git clone https://github.com/rwandantechy/ibyapa-nkotanyi-driving-school
cd ibyapa-nkotanyi-driving-school
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## About the Exam

The Rwanda provisional driving license exam is administered by the Rwanda National Police (RNP). Candidates must score at least 12/20 to pass, or 60% at the Busanza Automated Test Center. our platform has no affliation with RNP. Thank you!
