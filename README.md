
# IBYAPA v2

**Imyitozo y'Ikizamini cya Permi mu Rwanda**  
Practice for Rwanda's Driving License Exam — in Kinyarwanda, French, and English.

Live at [ibyapa.com](https://ibyapa.com)

---

## What is IBYAPA?

IBYAPA is a web app that helps people in Rwanda prepare for the provisional driving license (Permi) exam. It provides practice questions covering road signs, traffic rules, and driving regulations — the same topics tested by Rwanda National Police (RNP).

---

## Features

- **Multilingual** — Available in Kinyarwanda, Français, and English
- **Practice Questions** — Real exam-style questions with instant feedback
- **Correct Answers** — Review your mistakes and learn the right answers
- **Responsive** — Works on mobile and desktop
- **Authentication** — Sign in to track your progress

## Getting Started

```bash
# Clone the repo
git clone https://github.com/rwandantechy/ibyapa-v2.git
cd ibyapa-v2

# Install dependencies
npm install

# Start the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## About the Exam

The Rwanda provisional driving license exam is administered by the **Rwanda National Police (RNP)**. Candidates must score at least **12/20** to pass (or **60%** at the Busanza Automated Test Center).
